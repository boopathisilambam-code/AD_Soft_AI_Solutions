- `index.html` - page structure and all text (name, date, venue, phone, timeline, dress code)
- `css/style.css` - theme colors (top `:root` variables), layout, animations
- `js/main.js` - intro card, scroll lock, travelling chocolate, game, RSVP
- `assets/` - video and images (replace files, keep the same names)
